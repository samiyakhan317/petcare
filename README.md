# PetCare Management System

This project was developed for our **CSE370 Lab**.

## Project Description

PetCare is a Laravel-based pet care and grooming management system that allows customers, groomers, and administrators to manage pet grooming services and appointments.

## Main Features

* Customer registration and login
* Pet profile management
* Grooming appointment booking
* Grooming service management
* Groomer management
* Customer management
* Payment and billing management
* Grooming reports
* Loyalty points
* Admin dashboard

## Technologies Used

* Laravel
* PHP
* MySQL
* HTML
* CSS
* JavaScript
* XAMPP

## Installation

1. Clone the repository.
2. Install Laravel dependencies using Composer.
3. Create a `.env` file from `.env.example`.
4. Create the MySQL database.
5. Import the provided database SQL file.
6. Configure the database settings in `.env`.
7. Run the Laravel development server.

## Important

The `.env` file is not included in this repository because it contains local configuration and database credentials.
